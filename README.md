# Body Fixer Fitness

Fitness website built with React, TypeScript, Vite, Tailwind CSS, and Supabase.

## Run locally

1. Install Node.js.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env` and fill in your Supabase project URL and anon key.
4. Start the development server with `npm run dev`.

This project is a work in progress. Do not commit `.env` or other secrets.
